Provider-resilient engineering orchestration

Agent Relay

Beads stays authoritative while a neutral supervisor routes Claude, Codex, and agy through the same worktree, evidence, and review record.

Architecture

Beads
  |
  v
Neutral supervisor
  |
  +--> provider routing --> isolated worktree --> gates --> multi-vendor review
  |
  +--> checkpoint ledger --> resume / status
  |
  +--> human-only merge handoff

Workflow

  1. Recover the Bead, project law, and live store identity.
  2. Plan, checkpoint, and pause for durable decisions.
  3. Run one owned workstream per isolated worktree.
  4. Re-run gates independently and review with distinct vendors.
  5. Stop at a review-clean PR for human merge, or pause when vendor quorum is unavailable.

Safety model

  • Workers use bd --readonly; the supervisor is the only Beads writer.
  • Protected paths, blanket staging, remote mutation, and attribution are blocked.
  • Dirty worktrees are preserved for inspection instead of being deleted automatically.
  • Review-clean PR delivery runs only when delivery is configured; otherwise the run pauses for a human.
  • Version 0.1 is a local CLI/plugin package; a transient user service is optional future work, not a packaged requirement.

Setup

Install the plugin, then run relay setup --adapter example-app from the target project root.
